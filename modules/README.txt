Une description plus précise des modules peut être trouvé dans le rapport (fichier rapport_labo). Attention, les modules ne fonctionneront que dans un environnement incluant MnMS.

- NetworkManager : module pour la gestion et l'exploitation des fichiers réseaux MnMS;
- CopertEstimator : module pour le calcule de Copert et d'indicateurs globaux pour simulation MnMS;
- DemandVariation : module pour la génération de variations;
- DemandVariationCarSimulation1Res : module pour les simualtions groupées MnMS pour un réservoir et pour les voitures uniquement;
- Sensitivity : module générateur de tableaux de sensibilité;
- ClassificationUtils : module pour la construction de classification;
- Utils, SensitivityUtils, DemandVariationUtils : Utiliatires;
